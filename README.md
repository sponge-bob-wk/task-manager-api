# Task Manager API

Express.js 任务管理 API 项目。

## 运行

```bash
npm install
npm start
```

## 测试

```bash
npm test
```

## API

- `GET /health`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/tasks`
- `GET /api/tasks`
- `GET /api/tasks/:id`
- `PUT /api/tasks/:id`
- `DELETE /api/tasks/:id`
